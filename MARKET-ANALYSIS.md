### Modelo de Pricing Recomendado para PH

**Fórmula Base:**
```
Total = Base_Fare + (Distance × Rate_Per_Mile) + (Time × Rate_Per_Minute) + Surcharges
```

**Ejemplo:**
- Base: $5
- Distance: 10 miles × $2.50/mile = $25
- Time: 20 min × $0.50/min = $10
- Airport fee: $15
- **TOTAL: $55**

**Refinements:**
- Traffic-aware pricing (Google Maps real-time)
- Time-of-day multipliers (rush hour +20%)
- Day-of-week adjustments (weekend premium)

## 🔧 SISTEMAS DE COTIZACIÓN: INSTANT VS. MANUAL

### Instant Quote Systems (RECOMENDADO)

**Proceso:**
1. Usuario ingresa pickup/dropoff addresses
2. Google Maps Distance Matrix API call
3. Returns distance + estimated duration
4. Apply formula: `Base + (Distance × Rate/Mile) + (Time × Rate/Min) + Surcharges`
5. Display precio instantáneamente

**Pros:**
✅ Transparencia inmediata
✅ Tasas de conversión más altas (5X vs. manual)
✅ Better user experience
✅ Booking automatizado 24/7
✅ Capacidad de comparación competitiva
✅ Overhead operacional reducido
✅ Escalable para alto volumen

**Cons:**
❌ Complejidad para construir
❌ Requiere calibración constante
❌ Alto costo inicial de desarrollo ($15K-30K)

**IMPLEMENTACIÓN PH:** 🔴 CRÍTICO - Próxima fase

---

### Manual Quote Systems (Legacy)

**Proceso:**
1. Cliente submit request form
2. Operador revisa request (horas/días después)
3. Cálculo manual
4. Quote enviado via email/phone
5. Cliente accepts/declines

**Pros:**
✅ Flexibilidad para complex requests
✅ Human judgment para edge cases
✅ Menor inversión tecnológica

**Cons:**
❌ Slow response time (customer abandonment)
❌ Limitado a business hours
❌ Labor-intensive
❌ Inconsistent pricing
❌ Lower conversion rates (1/5 de instant)
❌ Not scalable
